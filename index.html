Privacy Policy & Transparency Guarantee

Last updated: November 2026 • 100% Client-Side Manifest V3

1. Zero Content Collection: WaitWise does not read, parse, copy, record, or transmit user prompts, questions, code snippets, or AI output responses. The extension's content script strictly looks for parent turn layout anchors in the DOM solely to mount the sponsored recommendation.

2. Minimal Host Permissions: The extension only activates on explicitly declared host origins (chatgpt.com, claude.ai, gemini.google.com). It does not hold blanket web permissions.

3. Shadow DOM Isolation: Sponsored cards are rendered within an encapsulated Shadow DOM tree to prevent CSS bleed, DOM leakage, or cross-origin access.

4. Revenue Payouts: Earnings are tracked via unique client-generated session tokens without requiring personally identifiable information. Payouts are fulfilled securely via Whop with a $10 minimum withdrawal threshold.
